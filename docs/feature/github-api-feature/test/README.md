# GitHub API Feature Test Plan

This folder holds milestone-specific tests for `github-api-feature`.

## Folder Layout
- `f2-github-api-integration/` - API fetch, cache, and fallback behavior
- `f3-manifest-manual-overrides/` - manifest merge and override behavior
- `f4-project-ordering-filtering/` - sort and filter rules
- `f1-project-card-display/` - card rendering and navigation behavior
- `f5-featured-vs-other-projects/` - featured section placement and separation rules
- `f6-resume-integration/` - resume repo exclusion and PDF display/download behavior

## Rule
If a milestone needs verification, add its tests inside the matching folder above.
